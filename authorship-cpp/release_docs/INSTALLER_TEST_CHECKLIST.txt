BEFORE INSTALLING
-----------------
 1. Check the download is the official build. In PowerShell, in the
    folder with the installer:
        Get-FileHash .\CALSS_Setup_1.2.0.exe -Algorithm SHA256
    The hash must equal the first line of CALSS_Setup_1.2.0_SHA256.txt.
    If it doesn't match, STOP and tell the developer.         ______

 2. Windows may warn about the download or show "Windows protected
    your PC" (SmartScreen). That happens because the installer is not
    code-signed (a thesis build has no paid signing certificate). It
    is expected. Only if step 1 matched: click "More info" ->
    "Run anyway". Write down exactly which warnings you saw:
    ____________________________________________________________


INSTALL
-------
 3. Run the installer. It asks "Install for all users" (needs an admin
    password once) or "Install for me only" (no admin). Pick ALL USERS
    if you can; note which one you used: ________          ______

    C:\Program Files\CALSS (all users) or
    ...\AppData\Local\Programs\CALSS (me only). Leave "Create a
    desktop shortcut" ticked. Finish installing.           ______
 5. Start Menu has "CALSS"; Desktop has "CALSS"; both show the CALSS
